# Online Feedback and Suggestion System for Cafeteria at TVET MARA Besut

> A planned web-based system to help students and staff share feedback and suggestions about the cafeteria at TVET MARA Besut.

## About the Project

The purpose of this project is to make it easier for students and staff to give feedback about cafeteria services, food, cleanliness, and other related matters. The system is intended to provide a simple online way to submit suggestions and help the cafeteria understand areas that may need improvement.

**Project status:** Planning / In development  
**Institution:** TVET MARA Besut  
**Planned technology:** React, Vite, and Firebase

## Why I Want to Build This

Feedback is useful for improving cafeteria services, but sharing it may not always be convenient. This project aims to provide a more accessible way for students and staff to send their opinions and suggestions online.

## Planned Features

- Online feedback and suggestion form
- Fields for basic user information, if required
- Feedback categories, such as food quality, service, cleanliness, and other issues
- Firebase database to store submitted feedback
- A simple interface that is easy to use on a phone or computer
- A possible administrator view to review feedback in the future

*These are planned features and may change as development continues.*

## Planned Workflow

1. A user opens the system through a website link or QR code.
2. The user fills in the feedback form.
3. The user submits the feedback.
4. The system stores the feedback using Firebase.
5. The responsible person can review the feedback and identify possible improvements.

## Planned Technology

| Technology | Intended use |
|---|---|
| HTML, CSS, and JavaScript | Web interface fundamentals |
